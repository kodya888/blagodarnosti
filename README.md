# Благодарности — личный дневник (PWA)

Две страницы:
1. **Запись** — ввод новой записи о благодарности / хорошем моменте.
2. **Список** — записи от самой новой к самой старой внизу списка.

Один пользователь, вход по e-mail и паролю. Данные хранятся в Supabase (облако, бесплатно).

## Шаг 1. Supabase (5 минут)

1. Зарегистрируйтесь на https://supabase.com → **New project** (название любое, пароль БД запомните не нужен, регион — ближе к вам, например Frankfurt).
2. Слева **SQL Editor** → **New query** → вставьте содержимое `schema.sql` → **Run**. Появится таблица `entries`.
3. **Project Settings → API**: скопируйте **Project URL** и **anon public key**.
4. Откройте `config.js` и вставьте их вместо `ВАШ-ПРОЕКТ` / `ВАШ-ANON-КЛЮЧ`.

## Шаг 2. Локальная отладка

В папке проекта:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000

- Первый вход: введите **свой e-mail и любой пароль (от 6 символов)** — аккаунт создастся автоматически, и вы войдёте.
- При первом входе Supabase пришлёт письмо «Confirm signup» — подтвердите его по ссылке (иначе сессия не сохранится между устройствами).
- Сохраните пару записей и проверьте список.

## Шаг 3. Бесплатный хостинг (Netlify Drop)

1. Откройте https://app.netlify.com/drop (нужен бесплатный аккаунт).
2. Перетащите папку `blagodarnosti` целиком в окно.
3. Получите адрес вида `https://имя.netlify.app`.

После этого на телефоне откройте этот адрес в Chrome → меню «⋮» → **«Добавить на главный экран»** — приложение установится как обычное (иконка «Б», полноэкранный режим, работает офлайн для чтения кэша).

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Разметка: вход, экран записи, экран списка |
| `styles.css` | Минималистичный белый стиль |
| `app.js` | Логика: вход, сохранение, список, удаление |
| `config.js` | URL и ключ Supabase (заполнить!) |
| `schema.sql` | Таблица + RLS в Supabase |
| `sw.js` | Сервис-воркер (офлайн-кэш) |
| `manifest.webmanifest` | Метаданные PWA, иконки |
| `icons/` | Иконки приложения |

## Безопасность

- Доступ к записям ограничен политикой RLS: каждый видит **только свои** строки.
- Анон-ключ публичный по дизайну Supabase — доступ контролируется логином.
- Дополнительно можно ограничить e-mail: в Supabase → **Authentication → Providers → Email** отключите «Allow new users to sign up» **после** того, как создали свой аккаунт — тогда никто другой не сможет зарегистрироваться.
